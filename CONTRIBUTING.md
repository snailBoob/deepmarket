# Feedback

Bug reports and feature ideas are welcome through GitHub Issues. Include the
Deepmarket version, exchange and symbol where relevant, browser, operating system,
and steps to reproduce. Remove private information from screenshots and logs.
Never include credentials or API keys.

Code contributions and pull requests are not currently accepted. You may still
modify and share your own version as permitted by the project license.
